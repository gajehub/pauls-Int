# Pauls International 웹사이트

- **사이트 주소**: https://paulsint.com
- **호스팅**: GitHub Pages (이 저장소의 `main` 브랜치)
- **도메인**: Cloudflare 등록, 2031-10-02 만료

이 문서는 **앞으로 혼자 고칠 때 보는 설명서**입니다.

---

## 1. 작업하는 기본 순서

고치는 내용이 무엇이든 순서는 항상 같습니다.

```
VS Code에서 고치기
  → 저장 (Ctrl+S)
  → Live Server로 눈으로 확인
  → GitHub Desktop에서 Commit
  → Push origin
  → 1~2분 뒤 사이트 반영
```

사이트가 옛 모습으로 보이면 브라우저에서 **Ctrl + Shift + R** 를 누르세요.
브라우저가 예전 파일을 기억하고 있어서 그렇습니다.

### 꼭 지킬 것

**Live Server로 확인하세요.** 파일을 더블클릭해서 열면(`file://`) 실제 사이트와
다르게 동작합니다. 사진이 안 보이는 등의 차이가 생깁니다.

Live Server 쓰는 법: VS Code에서 `index.html`을 열고 **우클릭 → Open with Live Server**.
(확장이 없으면 왼쪽 Extensions에서 `Live Server` 검색 후 Install)

**Push하면 바로 공개됩니다.** 미리 보는 단계가 따로 없습니다.

## 2. 인증서 사진만 바꾸기 (가장 흔한 일)

예: 수출인증자 인증서를 갱신받았다.

1. 새 인증서를 **WebP로 변환**합니다 (→ 4번 항목)
2. 파일 이름을 **기존과 똑같이** 바꿉니다 (`certification.webp`)
3. `img` 폴더에 덮어씁니다
4. Live Server로 확인 → Commit → Push

**HTML은 고칠 필요가 없습니다.** 파일 이름이 같으면 자동으로 새 사진이 나옵니다.

## 3. 인증서를 추가하기

1. 새 인증서를 WebP로 변환하고 `img` 폴더에 넣습니다.
   이름은 알아보기 쉽게 (예: `cert-oekotex.webp`, `cert-grs.webp`)

2. `index.html`에서 `<ul class="certs">` 를 찾습니다.
   (VS Code에서 **Ctrl + F** 로 `class="certs"` 검색)

3. 그 안에 주석으로 막아둔 예시가 있습니다. **주석 기호를 지우고** 값을 바꾸세요.

   주석 기호란 `<!--` 와 `-->` 입니다. 이 두 개를 지우면 코드가 살아납니다.

   ```html
   <li>
     <button
       class="button"
       type="button"
       data-cert="img/cert-oekotex.webp"
       data-label="OEKO-TEX certificate issued to Pauls International"
     >
       &rarr; OEKO-TEX certificate
     </button>
   </li>
   ```

   바꿀 곳은 세 군데입니다.

   | 항목 | 뜻 |
   |---|---|
   | `data-cert` | `img` 폴더에 넣은 파일 이름 |
   | `data-label` | 눈이 안 보이는 분이 듣게 되는 설명 |
   | 버튼 안의 글자 | 화면에 보이는 이름 |

4. 더 넣고 싶으면 `<li>` 부터 `</li>` 까지를 복사해 붙이고 값만 바꿉니다.
   몇 개가 되어도 코드의 다른 부분은 손댈 필요가 없습니다.

### 주의할 점

`&rarr;` 는 화살표(→)입니다. 그대로 두세요.
`<br />` 는 줄바꿈입니다. 글자가 길면 넣고, 짧으면 지우세요.
`&amp;` 는 `&` 기호입니다. HTML에서는 `&` 를 그냥 쓰면 안 됩니다.

## 4. 사진을 WebP로 바꾸기 (중요)

**사진을 그대로 올리면 안 됩니다.** 원래 이 사이트는 사진 때문에 12.5MB였고,
모바일에서 열리는 데 수십 초 걸렸습니다. WebP로 바꿔서 0.8MB가 되었습니다.
인증서 스캔은 보통 4MB가 넘으니 꼭 변환하세요.

### 방법: Squoosh (설치 불필요)

1. 브라우저에서 **https://squoosh.app** 접속
2. 사진을 끌어다 놓기
3. 오른쪽 아래 설정에서
   - 형식을 **WebP** 로 선택
   - **Quality** 를 `80` 정도로
   - **Resize** 를 켜고 **Width** 를 `1200` 으로 (인증서 기준)
4. 왼쪽 아래 다운로드 버튼으로 받기
5. 파일 이름을 바꿔서 `img` 폴더에 넣기

왼쪽이 원본, 오른쪽이 변환 결과입니다. 아래에 용량이 몇 % 줄었는지 나옵니다.
글자가 읽히는지 확대해서 확인하세요.

### 용량 기준

| 용도 | 가로 크기 | 목표 용량 |
|---|---|---|
| 인증서 | 1200px | 200KB 이하 |
| 대문 사진 | 1920px | 300KB 이하 |
| 원단 카드 | 640px | 100KB 이하 |

변환이 어려우면 원본 스캔을 Claude에게 주고 변환을 부탁하셔도 됩니다.

## 5. 글자만 바꾸기

`index.html`을 열고 Ctrl+F로 바꿀 문구를 검색해서 고치면 됩니다.

꺽쇠(`<`, `>`) 안쪽은 건드리지 마세요. 꺽쇠 **사이에 있는 글자**만 고칩니다.

```html
<h3 class="name">Polyester woven fabrics</h3>
                 ^^^^^^^^^^^^^^^^^^^^^^^ 이 부분만 고친다
```

## 6. 파일이 어떤 역할인지

| 파일 | 역할 |
|---|---|
| `index.html` | 사이트의 모든 내용 (글, 사진 위치, 구조) |
| `dist/css/styles.css` | 보이는 모양 (색, 크기, 배치) |
| `dist/css/reset.css` | 브라우저 기본 설정 초기화. 건드리지 않음 |
| `img/` | 사진 전부 |
| `CNAME` | `paulsint.com` 주소 설정. **지우면 사이트 주소가 깨집니다** |
| `sitemap.xml` | 검색엔진에 알려주는 페이지 목록 |
| `robots.txt` | 검색엔진 접근 규칙 |
| `google...html`, `naver...html` | 검색엔진 소유 확인 파일. 건드리지 않음 |

## 7. 망가졌을 때 되돌리기

GitHub Desktop에서:

1. **History** 탭
2. 되돌릴 커밋에 우클릭 → **Revert changes in commit**
3. **Push origin**

1~2분 뒤 원래대로 돌아옵니다. Git이 모든 변경을 기록하고 있으니
겁내지 않고 고쳐보셔도 됩니다.
